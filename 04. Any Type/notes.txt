
              ANY TYPE :

        * TypeScript has a special any type that can be represent any type... When a variable is annotated with the any type , TypeScript will allow it to have [any value] and disable all type checking for that variable and its properties...

              ANY TYPE (WARNING) :

        * While the any type can be useful in certain situations , it should be used sparingly.Overuse of any can lead to [untyped code] and make it harder to catch type-related bugs during development... it's generally better to use more specific type whenever possible to ger the benefits of TypeScript's type checking...
